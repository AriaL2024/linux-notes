##  Day 3 - Chapter 3:Investigating Linux’s Principles and Philosophy

Today,many computers architecture are x64,but previously x86 and x16 were used for designing computers and OSes

  - 16bit:it's very old architecture,this can create instructions with a length of 16 bits(today,use for embedded computers)
  - 32bits(x86):it's old architecture,this can create instructions with a length of 32 bits
  - 64bits(x64):it's today use it architecture,this can create instructions with a length of 64 bits

OSes have several architectures:

  - Monolithic:it's not flexible and modular,but this has vary speed.this structure doesn't have structure
  - Layer-base:it's flexible and modular,this has normal speed
  - Mircrokernel:it's very flexible and modular,but this has low speed for process
  - Hybrid:Combination of the Top architectures

throughout history,many OSe were Created,for example:

| OS Name | OS architecture | Base on | 
|---------|-----------------|--------------|
| VMS | Monolithic | VAX |
| DOS | Monolithic | DOS |
| Linux | Monolithic | UNIX-Like |
| BSD | Monolithic | UNIX-Like |
| Minix | Microkernel | UNIX-Like |
| Windows | Hybrid(Monolithic and Microkernel) | Windows |

The evolution of linux:

  - Improvements in linux kernel
  - Improvement in support tools
  - Creation of new support tools
  - Creation of new Distribution
